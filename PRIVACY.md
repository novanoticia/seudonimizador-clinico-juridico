# Política de privacidad

**Plugin:** seudonimizador-clinico-juridico
**Última actualización:** 2026-10-02
**Responsable del plugin:** Pablo ([mindandhealth.org](https://mindandhealth.org))

## Resumen

Este plugin **no recoge, no almacena y no envía datos a ningún servidor del autor**. Es un conjunto de instrucciones en texto (ficheros Markdown) que la IA que lo usa aplica sobre el texto que tú le das. Todo lo que pegues o adjuntes se queda dentro de esa conversación.

## Qué es el plugin y qué no es

- Contiene únicamente ficheros de texto: las instrucciones del skill, sus plantillas y la documentación. **No incluye código ejecutable, ni servidores MCP, ni conectores, ni scripts que se ejecuten al usarlo.**
- No hace llamadas a servicios externos ni envía información fuera de la conversación.
- No incluye analítica, telemetría, cookies ni identificadores de usuario.
- No accede a tu historial, a tu memoria ni a archivos distintos de los que tú aportas en la conversación.

## Qué datos trata

El plugin existe para procesar **el texto que el usuario aporta** (por ejemplo, el relato de un caso clínico o jurídico) y devolver una versión seudonimizada. Ese texto puede contener datos personales, incluidos datos sensibles como los de salud.

- El plugin **lee** ese texto durante la conversación para transformarlo.
- El plugin **no lo guarda** por su cuenta y **el autor no lo recibe ni puede acceder a él**.
- Se aplica el principio de mínimo necesario: el skill solo trabaja con el contenido que se le entrega para la tarea.

## Dónde se conservan los datos

Los datos que introduces los gestiona **la plataforma de IA en la que uses el plugin** (por ejemplo Claude, ChatGPT, Perplexity o Mistral), según sus propios términos y su política de privacidad. La retención del historial depende de esa plataforma y de tu configuración, y no de este plugin.

Por eso se recomienda:

- Usar una **conversación temporal** o equivalente antes de pegar nada sensible.
- Revisar la política de privacidad de la plataforma que utilices.
- No introducir datos identificativos reales sin una base legal para tratarlos.

## Lo que este plugin no garantiza

- La seudonimización **no equivale a la anonimización formal** que exigen el RGPD (Considerando 26) y la LOPDGDD para publicación, peritaje o expediente. Un texto seudonimizado puede seguir siendo dato personal.
- El resultado puede contener errores u omisiones. **Debe revisarlo siempre una persona** antes de usarlo, compartirlo o publicarlo; el skill incluye un modo de auditoría para ayudar en esa revisión, que no la sustituye.
- Este documento describe el funcionamiento del plugin y no constituye asesoramiento jurídico.

## Menores

El plugin está pensado para profesionales y estudiantes avanzados, no para menores de 18 años. Los casos que se seudonimizan pueden referirse a menores, pero eso es el contenido que se procesa, no quién usa el plugin.
